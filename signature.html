  1. Click Copy signature above.
  2. Outlook (desktop): File → Options → Mail → Signatures → New. Outlook (web): Settings → Mail → Compose and reply.
  3. Click into the signature editor and paste (Ctrl+V / ⌘V). The logo and details come in together.
  4. Set it as the default for New messages and Replies/forwards. Save.

The logo is embedded with a transparent background, so it travels with every email and sits on whatever colour the reader’s mail client uses — no attachment, no broken image, no box.
